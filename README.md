# AI-Based Driver Drowsiness Detection and Alert System

## Project Overview

This project investigates a low-cost, camera-based driver drowsiness detection system using edge AI.

The system aims to detect visual indicators of drowsiness and provide immediate local alerts using a buzzer, vibration motor and LED.

## Research Focus

The project investigates:

* Lightweight AI for edge devices
* Real-time drowsiness detection
* Local/offline processing
* Sequential vs. concurrent pipeline execution
* Latency and FPS comparison
* Memory and power considerations

## Proposed Pipeline

Camera Capture
→ Face/Eye Processing
→ Drowsiness Detection
→ Alert Generation

Two implementations will be evaluated:

1. Sequential pipeline
2. Concurrent/parallel pipeline
